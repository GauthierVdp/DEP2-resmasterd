Je hebt tweede zittijd voor het OLOD Data Engineering Project 2. Je bouwt individueel verder op het project van de eerste zittijd, maar de dataset is uitgebreid met de registraties van het tweede semester.

Opdracht

Een voorspellingsmodel opstellen dat, onafhankelijk van het academiejaar, voorspelt hoeveel studenten er in een bepaalde les aanwezig zullen zijn
De factoren bepalen die de aanwezigheid in de lessen beïnvloeden.
Een rapport opstellen in Power BI dat de aanwezigheid in kaart brengt per afstudeerrichting, OLOD, modeltraject, lesvorm en tijdstip (uur, dag, week).
Reflecteren op het verschil tussen semester 1 en semester 2. De dataset bevat nu registraties van beide semesters (uitsluitend Toegepaste Informatica). Onderzoek expliciet of en hoe het aanwezigheidspatroon verschilt tussen de twee semesters, en verwerk deze analyse in je rapport.
